# Locove 工作台界面

视觉基准为 [locove_2 菜单栏](research/assets/locove-stitch-workbench/menubar.png)、[locove_1 诊断](research/assets/locove-stitch-workbench/diagnosis.png)和 [locove_3 工作台](research/assets/locove-stitch-workbench/workbench.png)。

- 三个界面共用浅灰底、独立内容区、细分隔线和系统字体。使用蓝色主操作、绿色可用、琥珀色降级、红色故障和灰色停止。状态始终有文字。原生面板随 macOS 外观，网页同步适配浅色和深色。
- 菜单栏（locove_2）：左键、右键和 Control 点按打开同一个面板。顶部是刷新、主窗口、设置，其下可搜索。按收藏与运行中、需要处理、其他项目分组。单服务直接显示状态和主操作，多服务按需展开。底部保留添加项目、浏览器与退出。
- 诊断（locove_1）：在服务行内展开。先读故障原因与适用操作，再看入口、组件和依赖，最后看按需加载的真实日志。原生入口直接定位目标服务。保留原稿的结构，所有文案、状态和动作取实际运行事实。
- 工作台（locove_3）：单服务项目合并为一张卡片，名称与描述在左，状态与可复制入口靠近，主操作、日志和更多操作在右。多服务项目保留分组。最小窗口优先保证状态、按钮和长地址可读。项目侧栏仅显示异常标记。
